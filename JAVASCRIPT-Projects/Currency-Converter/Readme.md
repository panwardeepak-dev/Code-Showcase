# 💱 Currency Converter App

A responsive and lightweight **Currency Converter** built using **HTML, CSS, and JavaScript**, with real-time exchange rates powered by [@fawazahmed0's Currency API](https://github.com/fawazahmed0/currency-api).

This project is part of my frontend development journey, focusing on API integration, input validation, and real-time UI updates.

---

## ✨ Features

- Real-time exchange rate using CDN-based JSON API (no API key required)
- Simple and clean UI with modern styling
- Validates user input before processing
- Handles errors (e.g., invalid currency)
- Mobile-friendly layout
